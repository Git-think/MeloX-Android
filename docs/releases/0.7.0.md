# MeloX Android 0.7.0

发布日期：2026-10-25 · 标签：`0.7.0` · versionCode：`25`

## 新音源与播放

- 新增汽水音乐：支持抖音扫码登录、推荐、搜索、游标分页、歌单详情、账号歌单、歌词与播放；接口由本机直接访问，无需部署外部服务。
- 播放顺序统一为：当前音源 → 内置跨平台严格完整音频匹配（网易云、QQ音乐、酷狗概念版、汽水音乐、酷我、Bilibili）→ 已配置的 CHKSZ／LX。跨平台阶段需要开启“不可用资源从其他平台获取”，第三方阶段需要单独开启并同意协议。
- 修复 Bilibili 已收藏的他人收藏夹与视频合集：按类型使用对应接口并分页加载；单个失效或私有视频不再导致整页失败。
- 跨平台回退按顺序串行匹配，跳过刚失败的当前音源，只接受完整音频，不使用试听片段冒充。

## 设备互联与输出

- LAN 一起放：同步队列、切歌与跳转，准备最多等待 3 秒，迟到设备不追赶；结束误差在 5 秒内时等待最后一台设备。连接由进程级会话持有。
- 新增 DLNA 发现、SOAP 控制与本地 HTTP 音频服务；新增小米妙播（MiPlay）发现、连接、音量与断开。
- 新增实验性 USB 独占输出：当前仅面向全速 UAC1、双声道 PCM16、自适应／同步 OUT；不支持通用 DAC、UAC2、异步反馈、24／32 位或 DSD，也不宣称 bit-perfect。

## 歌词、设置与界面

- 酷狗概念版新增自动签到：每天首次启动时同时领取畅听 VIP 与申请概念版 VIP 升级；手动签到同样一次完成两项。当天成功不再请求，失败 10 分钟后重试，保留 `131001`／`20028` 提示，标准版账号仍不参与。
- 罗马音固定在每条视觉行原文正下方，并按发音单元覆盖的字符范围横向对齐；文字会进入相邻区域时单独缩小该条；跨换行单元按比例拆分到两行。
- 首次启动改为欢迎、账号、隐私协议与免责声明、云控选择的连续全屏引导；隐私政策与免责声明升级至 1.3。
- 歌词样式暂时只提供 Apple Music；EVA 与文字 PV 的渲染代码仍保留。
- 通知栏左侧播放模式按钮改为“列表循环 → 单曲循环 → 随机播放”三态循环，并分别使用对应图标。
- 更新弹窗限制在屏幕安全区内并设置最大高度，标题与按钮固定，更新日志区域可独立滚动；其他玻璃弹窗同步避开状态栏与导航栏。

## English

Release date: 2026-10-25 · Tag: `0.7.0` · versionCode: `25`

### New source and playback

- Added Qishui Music: Douyin QR sign-in, recommendations, search, cursor paging, playlist details, account playlists, lyrics and playback. Requests go directly from the device; no external service is required.
- Playback order is now: the current source → a strict full-audio match from another built-in source (NetEase, QQ Music, Kugou Lite, Qishui, Kuwo, Bilibili) → configured CHKSZ/LX resolvers. The cross-provider stage requires “fetch unavailable resources from other platforms”; the third-party stage requires its own switch and agreement.
- Fixed Bilibili collected folders and video collections: the correct endpoint is chosen per type and pages load incrementally; one deleted or private video no longer fails the whole page.
- Cross-provider fallback searches sources sequentially, skips the source that just failed, and accepts only complete audio, never a preview filler.

### Devices and output

- LAN Together now syncs the queue, track changes and seeks, waits up to 3 seconds for preparation, does not make late devices catch up, and waits for the last device when the ending offset is within 5 seconds. The connection lives in a process-level session.
- Added DLNA discovery, SOAP control and a local HTTP audio server, plus Xiaomi MiPlay discovery, connection, volume and disconnect.
- Added experimental USB exclusive output: full-speed UAC1, stereo PCM16 and adaptive/synchronous OUT only. Generic DACs, UAC2, asynchronous feedback, 24/32-bit and DSD are not supported, and bit-perfect playback is not claimed.

### Lyrics, settings and UI

- Kugou Lite now checks in automatically once a day, claiming both the free-listening VIP and the concept VIP upgrade. Manual check-in also performs both steps. Successful days are not retried; failures retry after 10 minutes, `131001`/`20028` remain distinct, and standard Kugou accounts are still excluded.
- Romanization is locked directly below its own visual lyric line, aligned to the exact characters of each pronunciation unit. A reading that would enter a neighbour’s area is scaled down on its own, and units crossing a wrap are split proportionally.
- First-run onboarding is now a continuous full-screen flow: welcome, account, privacy policy/disclaimer, then cloud-control choice. The privacy policy and disclaimer are version 1.3.
- Only the Apple Music lyric style is selectable for now; the EVA and Text PV renderers remain in the codebase.
- The notification play-mode button now cycles list loop → repeat one → shuffle with dedicated icons.
- Update dialogs stay inside the screen safe area with a maximum height, fixed title/buttons and an independently scrollable release-notes area. Other glass dialogs also avoid the status and navigation bars.
