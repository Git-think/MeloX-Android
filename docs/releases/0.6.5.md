# MeloX Android 0.6.5

发布日期：2026-10-18 · 标签：`v0.6.5` · versionCode：`24`

## 分屏与播放器

- 补发修复：恢复音乐库歌单打开 / 关闭时的封面共享过渡，保留分屏详情退场期间的内容。

- 设置 → 通用新增默认开启的分屏开关，可恢复单栏布局。
- Dock 与迷你播放器支持独立位置：左下、右下、左上、右上、左侧竖向、右侧竖向。
- 左右控件限制在各自半屏，适配屏幕安全区；顶部和侧栏位置为页面内容预留空间。
- 同位置保持竖屏间距并联动收缩；分开放置时不随页面滚动单独收缩。
- 修复设置子页面预测式返回，以及纯歌词页底部点按误跳进度。

## 多音乐源与 YouTube Music

- 搜索、歌曲菜单、集合详情和下载按真实音乐源能力分发，保留原始音源 ID。
- 补齐收藏、可写歌单、专辑、歌手和歌单内容分页，修复重复页与未知总数处理。
- YouTube Music 修复 browse 地区参数、浏览器会话采集及认证头；新增频道选择和刷新登录入口。
- 音乐库不再将账号资料请求失败误判为未登录，登录及频道切换后自动刷新。
- 可写歌单按服务端权限过滤，歌单移序按成员标识定位。

## 歌词与语言

- 所有音乐源共用歌词获取链，统一匹配、绑定、缓存、翻译语言与逐字歌词升级。
- 翻译语言选择对当前歌曲立即生效，无目标译文时保留原文，防止旧异步请求覆盖新语言。
- 恢复多语言资源与设置标题；Android 13 及以上支持应用语言选择，旧系统提供系统语言入口。
- 保留此前 0.6.5 开发阶段的签名文案热更新和受限 QuickJS 脚本能力。
