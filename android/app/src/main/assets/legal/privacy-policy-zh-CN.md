# MeloX 隐私政策

版本：1.3

生效日期：2026 年 10 月 25 日

MeloX 是开源的第三方 Android 音乐客户端。本政策说明 MeloX 在提供登录、音乐浏览、播放、歌词、下载、识曲、推荐、设备互联和系统集成功能时如何处理信息。MeloX 与 QQ音乐、网易云音乐、酷狗音乐、汽水音乐、抖音、Bilibili、Spotify、Apple Music 及其关联公司不存在隶属、合作或授权关系。

## 一、适用范围

本政策适用于 MeloX Android 应用本身。你在第三方音乐平台、系统浏览器、第三方登录网页或其他服务中提交的信息，还受相应第三方的隐私政策和服务条款约束。

## 二、我们处理的信息

### 1. 登录与账号信息

- 手机号登录时，MeloX 会将国家或地区代码、手机号和短信验证码直接发送给你选择的音乐平台，用于请求验证码和完成登录。
- 验证码仅用于当前登录请求，不会写入 MeloX 的账号存储。手机号可能在登录页面和安全验证回程期间短暂保留，以便恢复流程，但不会作为 MeloX 账号资料长期保存。
- 网页登录可能由 Android WebView 或系统浏览器承载。第三方页面可能设置 Cookie；登录成功后，MeloX 会在应用私有存储或 WebView Cookie 存储中保存维持会话所需的 Cookie、Token、用户标识和有效期信息。
- Spotify 授权使用 Authorization Code + PKCE，不使用 Client Secret。授权过程中会临时保存 PKCE 校验信息，并在本机保存访问令牌和刷新令牌。
- Apple Music 配置可能保存由你提供的 Developer Token、Music User Token 和 storefront。MeloX 不要求或保存 Apple 账户密码。
- 汽水音乐扫码登录需要使用抖音 App 扫码并在平台侧确认。MeloX 会向平台请求二维码、轮询授权状态，并在校验成功后将维持账号访问所需的会话凭据加密保存在本机；不要求输入或保存抖音账号密码。扫码及账号关联由汽水音乐／抖音处理。内置汽水接口由本机直接访问，无需另行部署参考项目的服务器。
- 酷狗概念版账号与历史酷狗标准版凭据隔离保存，不自动迁移或混用。你主动确认领取会员或升级时，MeloX 才会向酷狗提交相应请求，并读取会员状态、有效期和领取结果。

### 2. 音乐与使用数据

- 为展示和操作你的内容，MeloX 可能从所选平台读取账号资料、收藏、歌单、专辑、关注关系、播放记录、搜索结果和音乐元数据。
- 播放队列、播放位置、最近播放、收藏操作、下载记录、音质选择、歌词偏好和应用设置可能保存在本机。
- 当你主动启用“不可用资源从其他平台获取”后，仅在当前平台明确没有返回可播放音频时，MeloX 可能把歌曲标题、歌手和时长发送给 QQ音乐、酷狗音乐或 Bilibili 的搜索接口，用于寻找严格匹配的完整音源。该功能默认关闭，不采用试听片段，也不用于绕过平台访问限制。
- 启用本地个性化推荐后，MeloX 会在获得单独同意的前提下，在本机处理播放次数、完成度、跳过记录、喜欢状态、歌曲特征和来源偏好。当前版本不会将本地推荐模型上传到 MeloX 服务器。

### 3. 缓存、下载与媒体文件

- 为提高播放和浏览速度，MeloX 可能缓存音频分片、封面、歌词、接口响应和其他媒体数据。
- 你主动下载的音乐、封面或歌词可能保存在应用目录或你授权的设备存储位置，直到你在应用中删除、清除应用数据或卸载应用。

### 4. 麦克风、剪贴板、通知与悬浮显示

- 仅在你主动使用听歌识曲或持续识别并授予麦克风权限后，MeloX 才会采集必要的短时音频或生成音频指纹。识别请求可能发送给相应的第三方识别服务；除非功能界面另有明确说明，MeloX 不长期保存原始麦克风音频。
- 启用剪贴板链接识别后，MeloX 会在本机检查剪贴板中的受支持音乐链接，不会将无关剪贴板内容上传给 MeloX。
- 启用媒体通知、锁屏信息、系统歌词或悬浮歌词后，歌曲名、歌手、封面和歌词可能显示在通知栏、锁屏、画中画或其他应用上层。请根据设备使用环境决定是否开启。

### 5. 技术信息

- 第三方平台在接收网络请求时，可能获取你的 IP 地址、请求时间、设备和客户端标识、User-Agent 及必要的接口参数。
- 如果你主动开启并配置第三方音乐源，相关搜索词、播放请求和配置内容可能直接发送给对应第三方；该第三方音乐源不在 MeloX 云控范围内，其数据处理由对应提供者负责。
- MeloX 可能在设备本地生成运行日志和错误信息，用于诊断。当前版本不内置广告 SDK，也不运营用于集中收集用户行为或崩溃数据的自有分析服务。
- 检查更新时，应用可能访问使用 DNS-over-HTTPS 解析的 GitHub，或你选择的 GhFast、GhProxy、GhProxy.org 下载源；这些服务会按其自身政策处理网络请求信息。

### 6. 设备互联与外部音频输出

- 启用 MeloX 局域网互联、DLNA 或小米 MiPlay 时，应用可能通过局域网广播、多播、套接字或系统服务发现和连接设备。参与设备或服务可能接收设备名称、网络地址、设备／会话标识、播放状态、曲名、歌手、封面地址、播放队列、进度、音量及控制指令。
- 投送、接力或一起放可能向接收设备提供媒体地址，或通过本机临时 HTTP 音频服务传送播放所需的数据；这些数据会对接收设备及可访问该服务的网络参与者暴露。局域网连接不保证端到端加密，请在可信网络使用，并妥善保管配对 PIN。
- 局域网设置可能在本机保存设备标识、名称、PIN、受信任设备及连接偏好。关闭设备面板不会自动结束已建立的连接；请使用断开或停止输出操作结束会话。
- 实验性 USB 输出仅在你选择设备并授予系统 USB 访问权限后，读取 USB 描述符并向设备传送解码后的 PCM 音频及必要控制数据。该输出流程本身不向远程服务器上传音频；原音源的网络请求仍由所选平台处理。

## 三、信息如何使用

MeloX 仅为完成你主动请求的登录、内容同步、搜索、播放、歌词、收藏、歌单操作、下载、推荐、识曲、更新检查和系统集成功能而处理上述信息。MeloX 不出售你的个人信息，也不会将账号凭据用于与这些功能无关的广告画像或营销。

## 四、第三方服务与信息传输

根据你启用的来源和功能，信息可能直接传输给 QQ音乐、网易云音乐、酷狗音乐、汽水音乐／抖音、Bilibili、Spotify、Apple Music、GitHub，以及实际提供歌词、媒体或识曲结果的第三方服务。设备互联还会向你连接的接收设备及相关系统服务提供必要数据。部分服务的服务器可能位于你所在国家或地区之外。使用相应功能前，请同时阅读该服务的隐私政策和账号条款。

## 五、本地保存期限

- 登录凭据通常保存至你退出对应账号、清除该服务配置、清除应用数据或卸载应用。
- 缓存保留至系统或 MeloX 自动清理、你手动清理、清除应用数据或卸载应用。
- 下载内容保留至你手动删除或移除对应存储。
- 本地推荐数据保留至你撤回个性化同意并删除模型数据、清除应用数据或卸载应用。
- 验证码只在当前登录过程中使用，不作为持久账号数据保存。
- 局域网配对和受信任设备信息保留至你在相应设置中移除或重置、清除应用数据或卸载应用；仅断开连接不会必然删除已保存的信任关系。

## 六、你的选择与权利

- 你可以拒绝非必要权限；对应功能可能不可用，但不影响不依赖该权限的其他功能。
- 你可以在设置中管理音乐服务、退出账号、清理缓存和下载，并撤回本地个性化推荐同意。
- 你可以通过 Android 系统设置撤回麦克风、通知、悬浮窗等权限。
- 你可以停止设备发现、断开互联、移除受信任设备或停止 USB 输出；拔出 USB 设备也会结束相应输出。移除本地凭据不会自动撤销平台侧已授予的授权，可同时在第三方平台管理授权和登录设备。
- 你可以通过清除应用数据或卸载 MeloX 删除应用私有存储中的全部本地数据。第三方平台服务器中的数据应在对应平台内管理。

## 七、安全说明

MeloX 使用 Android 应用沙箱保存私有数据，并尽量减少凭据暴露范围。但任何本地存储、网络传输或第三方接口都无法保证绝对安全。请保护设备解锁方式，不要向他人提供验证码、Cookie、Token 或调试日志。

## 八、未成年人

未成年人应在监护人指导下使用 MeloX，并遵守所连接音乐平台对年龄和账号使用的要求。若你无权同意本政策，请停止使用需要个人信息的功能。

## 九、政策更新

功能、数据来源或法律要求变化时，本政策可能更新。重大变更会通过应用内提示要求你重新阅读或确认。页面顶部的版本和生效日期用于识别当前文本。

如对隐私处理、数据删除或本政策有疑问，请通过 MeloX 项目主页的 GitHub Issues 联系维护者：https://github.com/Git-think/MeloX-Android/issues
